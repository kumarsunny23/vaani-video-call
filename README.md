# 🎥 Vaani Video Calling App

A real-time video calling web application built using the **MERN Stack (MongoDB, Express, React, Node.js)**. This project enables users to connect instantly through secure and smooth video calls.

---

## 🚀 Features

* 🔐 User Authentication (Login/Signup)
* 📞 One-to-One Video Calling
* 💬 Real-time Communication
* ⚡ Fast & Responsive UI
* 🌐 WebRTC / Socket-based connection
* 📱 Mobile-friendly design

---

## 🛠️ Tech Stack

**Frontend:**

* React.js
* Tailwind CSS / CSS

**Backend:**

* Node.js
* Express.js

**Database:**

* MongoDB

**Other Tools:**

* Socket.io (for real-time communication)
* WebRTC (for video calling)

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/vaani-video-call.git
cd vaani-video-call
```

### 2. Install dependencies

**For backend:**

```
cd server
npm install
```

**For frontend:**

```
cd client
npm install
```

---

### 3. Setup Environment Variables

Create a `.env` file in the server folder and add:

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

---

### 4. Run the application

**Start backend:**

```
cd server
npm run dev
```

**Start frontend:**

```
cd client
npm start
```
